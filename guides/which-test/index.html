Which statistical test should I use?

Answer a few questions about your data and get the test, the SciPy call, and what to report with it.

Decide the test before you look at the results — choosing it afterwards is a forking path. Whatever the test says, report the effect size and a confidence interval alongside the p-value.

What are you comparing?
One group’s average against a fixed value
Is the data roughly normal, or do you have 30+ observations?
Yes
Use
One-sample t-test
scipy.stats.ttest_1samp(x, popmean)

Compares the sample mean with the fixed value, scaled by its standard error.

No — small and skewed
Use
Wilcoxon signed-rank test (or a bootstrap interval)
scipy.stats.wilcoxon(x - value)

Uses ranks of the differences, so a few extreme values cannot dominate.

Two groups
Are the measurements paired — the same units measured twice?
Paired (before/after, same users, same folds)
Are the differences roughly normal, or are there 30+ pairs?
Yes
Use
Paired t-test
scipy.stats.ttest_rel(after, before)

Tests the mean of the paired differences; far more sensitive than treating the groups as independent.

Wilcoxon signed-rank test

Independent groups
What kind of outcome?
A number, roughly normal or with large samples
Use
Welch’s t-test
scipy.stats.ttest_ind(a, b, equal_var=False)

The safe default for two means: it does not assume equal variances.

A number with heavy tails, outliers, or ranks
Use
Mann–Whitney U test
scipy.stats.mannwhitneyu(a, b)

Tests whether one group tends to have larger values; with heavy tails it can be far more powerful than the t-test.

Yes/no — a proportion (conversion, defect rate)
Do you expect at least 5 cases in every cell of the 2×2 table?
Yes
Use
Chi-square test (or two-proportion z-test)
scipy.stats.chi2_contingency(table)

Compares observed counts with those expected if the groups did not differ. For A/B tests, a Bayesian view is in Bayesian A/B.

Fisher’s exact test
scipy.stats.fisher_exact(table)

Exact for small samples, where the chi-square approximation breaks down.

Three or more groups
What kind of outcome?
A number, roughly normal
Use
One-way ANOVA, then Tukey’s HSD
scipy.stats.f_oneway(a, b, c) # then statsmodels pairwise_tukeyhsd

ANOVA says whether any group differs; the post-hoc test says which, while controlling for the extra comparisons. Use Welch’s ANOVA if the spreads differ a lot.

A number, skewed or with outliers

scipy.stats.kruskal(a, b, c)

The rank-based version of ANOVA; follow up with pairwise tests and a multiple-testing correction.

Whether two variables are related
What do the variables look like?
Both numeric, roughly linear
Use
Pearson correlation
scipy.stats.pearsonr(x, y)

Measures straight-line association. Plot it first — r = 0 can hide a strong curved relationship.

Numeric but curved, ranked, or with outliers
Use
Spearman rank correlation (or mutual information)
scipy.stats.spearmanr(x, y)

Captures any monotonic relationship; mutual information captures non-monotonic ones too.
