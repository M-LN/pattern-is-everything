Which metric should I evaluate my model with?

From what your model predicts and what its mistakes cost to the metric that measures it honestly.

Pick the metric before you run experiments, compare every model against a simple baseline, and measure on held-out data with a validation scheme that matches how the model will be used.

What does the model predict?
A class (yes/no, or one of several)
How common is the class you care about?
Reasonably common (20–80%)
Will you use the predicted probabilities, or only the decisions?
The probabilities (risk scores, pricing, ranking with thresholds later)
Use
Log loss or Brier score, plus a calibration plot

Rewards probabilities that are both sharp and honest; accuracy ignores how confident the model was.

Which mistake costs more?
Missing a real case
Use
Recall at a fixed precision, and the area under the precision–recall curve

Accuracy is meaningless here (predicting “no” for everything scores 99%). Set the threshold from the cost of each error.

Use

What do large errors cost?
In proportion to their size
Use
MAE (mean absolute error)

In the units of the target and robust to outliers; it rewards predicting the median.

Big errors are much worse than small ones
Use
RMSE

Squares errors before averaging, so big misses dominate; it rewards predicting the mean.

I compare across series of very different scale
Use
MASE (not MAPE)

Scales error by a naive forecast’s error; MAPE explodes near zero and treats over- and under-forecasts differently.

I need to say how much variation is explained
Use
R² on held-out data

A comparison with predicting the mean; on new data it can be negative.
