# Pattern is Everything — case notebooks

The four case studies (https://patterniseverything.com/cases/), on real public data. Each notebook holds
the case page's steps and is generated by `scripts/build-cases.py`; its first cell fetches the data file
if it is not already next to the notebook. On the site, every step can also be run in the browser.

- `case-housing-regression.ipynb` — California Housing (1990 census): random vs regional cross-validation, and a top-coded target.
- `case-credit-default.ipynb` — Default of Credit Card Clients (UCI): undocumented codes, accuracy vs the majority class, a cost-based threshold.
- `case-energy-forecast.ipynb` — one household's electricity (UCI): missing minutes, naive baselines walk-forward, a regression against a 7-day mean.
- `case-market-backtest.ipynb` — the 200-day rule on a century of daily US market returns (Kenneth R. French Data Library, downloaded by the notebook): eras, costs, a look-ahead bug.

JupyterLite runs Python in the browser (Pyodide); the market notebook needs a local Jupyter, because a
browser cannot download its data from the French library.
