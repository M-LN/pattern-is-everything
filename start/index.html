Guided Learning Path

From intuition to working experiments

Use this path when you want a clear route through the site: understand the pattern, build a small model, evaluate it honestly, then test assumptions in a browser lab or sandbox.

Recommended order
  1. Begin with data shape and model metrics.
  2. Learn how models fit, fail, and generalize.
  3. Run a local dataset case.
  4. Use Build Mode or the browser lab to save experiments.
  5. Treat market patterns as hypotheses, not proof.
